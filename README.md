<h1 align="center">Projects</h1>

<h2 align="center"><a href="https://github.com/hrobertoCS/macro-rpg-prototypes">MacroRPG</a></h2>

<p align="center">Nutrition tracking app with RPG progression. Log meals and track daily macros against set targets to earn XP based on how closely you meet your targets.</p>

<p align="center">Built using TypeScript, React Native, Expo, and SQLite.</p>

<h2 align="center"><a href="https://github.com/hrobertoCS/macro-rpg-prototypes#demo">Demo</a></h2>

<h2 align="center"><a href="https://github.com/hrobertoCS/cs465-fullstack">Travlr Getaways</a></h2>

<p align="center">Full-stack travel package application with an administrator interface for managing trips, MongoDB data storage, and JWT authentication.</p>
<p align="center">Built using MongoDB, Express.js, Angular, and Node.js.</p>

<h2 align="center"><a href="https://github.com/hrobertoCS/InventoryTracker">InventoryTracker</a></h2>

<p align="center">Android inventory management app with account registration and login, item and quantity management, a grid inventory view, and optional low stock alerts through SMS.</p>

<p align="center">Built using Java, Android Studio, and SQLite.</p>
